# VilniaMC — збірка

Файли збірки зимового сервера **VilniaMC**. Їх автоматично завантажує мод-завантажувач VilniaMC:
гравцю достатньо покласти в папку `mods` один файл завантажувача, все інше він встановить і оновлюватиме сам.

`manifest.json` підписаний ключем сервера — підроблену збірку завантажувач не прийме.
